# 君成时代 Juncheng-AIFilm · 智能影视传媒工坊
**Juncheng-AIFilm-Studio** · 企业品牌、智能影视内容生产流程与商业影像合作展示。

北京君成时代科技有限公司的官方网站与数字影像工坊，用于介绍 AI 影视方向、影视智能体流程、商业影像方案及合作入口。

[官方网站](https://xingtian.net/)

## 页面内容

- 企业定位与品牌介绍。
- AI 影视 Agent 流程的展示性说明。
- 商业影像方案和案例内容。
- 联系与预约入口。

案例、资质和服务承诺以企业可验证材料为准。示意素材不能替代真实交付证明，表单展示也不意味着已接入邮件或客户系统。

## 技术结构

原生 HTML、CSS、JavaScript；Node.js 内置测试框架。

```text
index.html     页面入口
src/           内容、渲染、样式与交互
public/        品牌和视觉资源
tests/         内容、资源与交互约束测试
docs/          项目说明
```

## 本地运行与测试

```sh
npm run serve
npm test
```

本地预览为 `http://127.0.0.1:4173/`，无需业务数据库。内容优先通过现有 `src/` 配置维护，避免在多份页面中重复修改。

## 生产发布

域名为 `xingtian.net`。由 Nginx 提供静态页面。更新时保留 HTTPS 配置，先备份站点，再检查页面、资源路径、手机布局和联系方式。

服务器无需 Node.js 运行此静态页面；Node.js 用于本地测试。不要向仓库上传证书私钥、内部业务文件或个人联系方式清单。历史源码和测试保留，仓库改名不改变线上域名。

## 内容审核

公开案例须经授权；资质、专利和申报状态应与真实记录一致。AI 生成视觉素材用于展示时应避免误导其为真实拍摄或已完成客户项目。
