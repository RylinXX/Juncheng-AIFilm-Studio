# AI影视公司官网设计规格

日期：2026-05-08

公司名称：北京君成时代科技有限公司

## 目标

为北京君成时代科技有限公司设计一款品牌展示型 AI 影视科技公司官网。官网第一版重点面向投资人和合作伙伴，目标不是做复杂产品平台，而是快速建立可信度，并引导访客预约 AI 影视能力演示。

核心转化目标：预约 AI 影视能力演示。

## 受众

第一优先级受众是投资人和合作伙伴。他们需要快速判断：

- 公司做什么：AI 影视技术与商业化影视方案。
- 凭什么可信：网文网、ICP、广电等内容产业资质，专利布局，软件著作权，国家高新技术企业认证申报筹备中。
- 技术壁垒在哪里：自研影视 Agent 流程。
- 商业落地在哪里：可交付的商业化影视方案和匿名项目经验。
- 下一步怎么验证：预约一次 AI 影视能力演示。

## 定位与信息架构

主方案采用“投资人信任优先”，融合“预约演示”的强转化入口。首页以单页落地页为第一版形态，模块顺序如下：

1. 首屏定位与主转化：用自研影视 Agent 流程，驱动商业影像智能化生产。
2. 资质与技术资产：网文网、ICP、广电、专利、软著、国高新申报筹备中。
3. 影视 Agent 流程：剧本理解、分镜规划、影像资产生成、剪辑包装、交付评估。
4. 商业化影视方案：品牌宣传片、广告视觉、虚拟人物内容、短剧/短视频矩阵、产业宣发影像。
5. 匿名项目经验：以行业、目标、交付方案和结果表达项目成熟度，不虚构公开客户。
6. 合作路径：预约演示、需求诊断、方案验证、商务合作。
7. 最终 CTA：再次引导预约 AI 影视能力演示。

## 页面模块

### 1. 首屏 Hero

建议主标题：

> 用自研影视 Agent 流程，驱动商业影像智能化生产

建议副标题：

> 北京君成时代科技有限公司专注 AI 影视技术与商业化内容方案，面向品牌、机构与产业合作伙伴提供从创意开发到影像交付的智能化流程能力。

主按钮：预约 AI 影视能力演示

辅助按钮：了解影视 Agent 流程

首屏右侧或背景展示动态 Agent Pipeline，而不是静态装饰图。

### 2. 资质与技术资产

资质必须具体写，不使用笼统“三证齐备”作为唯一表达。

展示项：

- 网文网：网络文化经营相关资质，最终以实际证照全称为准。
- ICP：互联网信息服务相关资质，最终以实际证照全称或备案/许可证信息为准。
- 广电：影视/视听业务相关资质，最终以实际证照全称为准。
- 专利布局：展示已授权或已申请状态，按实际情况标注。
- 软件著作权：展示系统能力沉淀，按实际名称填写。
- 国家高新技术企业认证申报筹备中：不得写成已认证或已通过。

### 3. 影视 Agent 流程

以流程图或横向节点图呈现：

1. 剧本理解：识别主题、角色、场景、镜头目标。
2. 分镜规划：输出可执行镜头方案和内容结构。
3. 影像资产生成：调度图像、视频、声音、虚拟人物等生成能力。
4. 剪辑包装：生成节奏、字幕、包装、版本适配。
5. 交付评估：围绕商业目标、传播场景和内容质量做反馈。

重点文案：把影视创意生产拆成可调度、可复用、可演示的智能工作流。

### 4. 商业化影视方案

展示公司不仅有技术流程，也能做商业内容落地：

- 品牌宣传片
- 广告视觉
- 虚拟人物内容
- 短剧/短视频矩阵
- 产业宣发影像

每个方案卡片应包含“适用场景、交付内容、AI 提效点、可预约演示”的结构。

### 5. 匿名项目经验

不虚构客户名称，不包装假案例。使用匿名行业项目表达成熟度，例如：

- 某消费品牌视觉升级项目
- 某产业园招商宣传项目
- 某教育内容短视频项目

每个匿名项目应包含：

- 行业
- 目标
- 交付内容
- 使用的 AI 影视流程
- 可公开表达的结果或阶段性成果

如没有真实可公开结果，则写成“能力验证/方案验证”，不写成已交付客户案例。

## 视觉系统

视觉方向：科技银蓝。

主色建议：

- 深蓝黑：`#071421`
- 科技深蓝：`#0c2a45`
- 亮银蓝：`#3aa8ff`
- 冰蓝：`#d9efff`
- 冰白：`#f7fbff`

视觉语言：

- 银蓝渐变背景
- 细网格和坐标线
- 玻璃拟态信息卡片
- Agent 流程节点
- 影像光轨和数据流线
- 克制的科技发布感

字体方向：使用现代、清晰、有科技感的中文与西文字体组合，避免默认系统字体带来的模板感。实现时优先选择可商用 Web Font 或本地安全字体，并确保中文渲染稳定。

## 首屏动态效果

首屏可以加入动态效果，但必须服务信任和流程表达，不能变成炫技动画。

建议动态效果：

- 背景细网格缓慢漂移，模拟影像计算空间。
- 银蓝光轨从左下向右上缓慢穿行，形成影视/数据流动感。
- Agent Pipeline 节点依次点亮：剧本、分镜、生成、剪辑、交付。
- 标题、副标题、CTA 分层缓入，节奏控制在 800-1200ms。
- 右侧流程预览卡片有轻微浮动和发光脉冲。

性能边界：

- 动效优先用 CSS transform、opacity、background-position 实现。
- 避免首屏大体积视频背景。
- 避免高频粒子系统或大量 canvas 对象。
- 移动端降低动画复杂度，尊重 `prefers-reduced-motion`。

## 交互与转化

主 CTA：“预约 AI 影视能力演示”。

第一版可接以下任一方式：

- 表单：姓名、公司、联系方式、合作需求。
- 邮箱：跳转邮件客户端或复制邮箱。
- 企业微信/二维码：适合作为快速联系入口。

表单成功状态必须明确反馈，例如“已收到预约请求，我们会尽快联系你”。失败状态必须给出替代联系路径。

## 技术边界

第一版做静态品牌官网或轻量单页应用，不做账号系统、后台管理、在线视频生成产品或复杂 CRM。

建议实现边界：

- 响应式页面，桌面优先，移动端完整适配。
- 首屏和核心内容静态渲染优先，保证加载速度。
- 动效轻量化，不依赖重型 3D 或视频资源。
- 预约表单可先接简单接口、第三方表单、邮箱或企微入口。
- 资质和案例内容预留可维护的数据结构，便于后续替换真实证照名称、证号和项目材料。

## 合规与文案规则

- 不虚构客户名称或公开案例。
- 匿名项目必须明确为匿名行业经验、能力验证或方案验证。
- 国高新只写“国家高新技术企业认证申报筹备中”或“筹备中”，不得暗示已获得。
- 专利和软著按真实状态标注，区分已授权、申请中、登记完成等状态。
- 网文网、ICP、广电必须以实际证照全称和证照状态为准。
- 不写“行业第一”“唯一”“国家级认证已获批”等无法证明的绝对化表述。

## 验证标准

设计通过后，实现阶段至少验证：

- 桌面端首屏在 1440px 宽度下视觉完整，CTA 明确可见。
- 移动端首屏在 390px 宽度下文案不溢出，CTA 可点击。
- 首屏动效不影响正文可读性。
- `prefers-reduced-motion` 下关键动画可降级或关闭。
- 预约演示入口有明确成功或替代联系反馈。
- 页面中没有将筹备中资质写成已获认证。
- 匿名项目没有虚构公开客户名称。
